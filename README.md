# מתחם 13 – סימולציית עסקאות — גוש 10027 חלקה 33, חדרה

מערכת תומכת החלטה לבעלי זכויות בתכנית 302-1306018: **מהי הדרך המשתלמת והמתאימה ביותר לממש את זכויות הקרקע שלי, בהתאם ליכולת הכלכלית שלי?**

ארבע שאלות אישיות (שטח, הון פנוי, החזר חודשי, מה חשוב לי), ההצעה של היזם (אחוז קומבינציה 25–45% ו**מה היזם משלם באחוז הזה** — כלום, היטל ההשבחה, או הכול) ורווח יזמי 15–20%. המנוע:

1. מייצר אוטומטית מסלולים רגילים ומשולבים: מכירה, קומבינציה, שירותי בנייה, תמורות, מכירה חלקית ובנייה, השלמה לדירה שלמה, בנייה ומכירת דירה, השכרה, המתנה ורכישת זכויות משלימות — לכל מספר דירות שלמות אפשרי.
2. מחשב עלויות, מסים (רזרבות שמרניות), משכנתא ותזרים חודשי לאורך 10 שנים. מימון המסים (הלוואת מסים מהיזם או מהבנק, הלוואה על נכס אחר) לא מונח — הוא נבדק כאפשרות מותנית, עם העלות שלו. הדירוג לפי הערך הנוכחי לכם (כולל מימון, בהיוון ריאלי של 3%), ומודל היזם מבוסס על שטחי התכנית ואומדן עלויות הבנייה של לשכת השמאים.
3. פוסל מסלולים שחורגים מההון, מההחזר החודשי או ממגבלות המימון, ובודק אותם בשלושה תרחישים.
4. מדרג לפי המטרה, מסביר בעברית פשוטה, ומחשב **מה לבקש מהיזם** — מחיר מינימלי לזכויות, עלות בנייה מקסימלית, אחוז קומבינציה נדרש ועוד.

הכול רץ בדפדפן. אין שרת, אין הרשמה, אין AI חיצוני ואין שליחת נתונים.

בכניסה הראשונה אשף קצר מוביל דרך השאלות וההנחות החשובות; בסיומו אפשר לשמור את התשובות בדפדפן בלבד, ובפעם הבאה מגיעים ישר לתוצאות.

## המחשבון המקורי (השוואה מתקדמת)


אפליקציית React (RTL) לבעלי זכויות בגוש 10027 חלקה 33, בתכנית 302-1306018. המערכת מחשבת לפי **טבלאות האיזון וההקצאה** כמה יחידות מגיעות לכל בעל זכויות ומה שוויין. היא מציגה ארבעה מסלולי התקשרות עם יזם:

1. **קומבינציה** — אחוז מהזכויות כדירות מוגמרות (ברירת מחדל 35%).
2. **שירותי בנייה (עלות+)** — בונים את כל הזכויות בעצמכם מול עמלת יזם.
3. **תמורות** — אחוז מהכנסות המכירה.
4. **מזומן** — מכירת הזכויות לפי מחיר למ״ר קרקע.

העיצוב זהה לאפליקציית [compound-13-tables](https://github.com/avishayil/compound-13-tables) (מחשבון הזכויות של מתחם 13).

## הטבלאות

כל החישובים לפי **טבלאות האיזון וההקצאה המעודכנות** (עדכון לפי סעיף 106(ב), 23/11/2026) בלבד. השטח במ״ר (167, 334 מ״ר וכו׳) הוא רק דרך נוחה לתאר את החלק בחלקה המקורית.

| | עדכון לפי סעיף 106(ב) (23/11/2026) |
|---|---|
| מגרשים לבעלי חלקה 33 | 149 / 150 / 153 (מגורים ד׳, 102 / 96 / 100 יח״ד) |
| חלק במגרש לכל 167 מ״ר | 2353/100000 (149, 150), 2365/100000 (153) → כ-2.4 יח״ד |
| שווי זכויות ל-167 מ״ר | ₪714,371 (149/150), ₪714,467 (153) |
| שווי החלקה במצב הנכנס | ₪25,521,300 |

הנתונים מרוכזים ב-[`src/data/parcel33.js`](src/data/parcel33.js), עם הפניה לעמודים במקור. הקובץ לא כולל שמות או מספרי זהות.

נתוני המגרשים זהים לטבלאות המגרשים שאומתו מול שורות הסיכום בפרויקט compound-13-tables. מסמכי המקור נשמרים מקומית ב-`to-review/`, שאינה נכנסת לגיט כי הטבלאות השמיות כוללות פרטים אישיים.

## איך מחושב

[`src/utils/simulationMath.js`](src/utils/simulationMath.js) מכיל פונקציות טהורות ומכוסה בבדיקות.

**זכויות לפי הטבלה** (`computeTableRights`):
- **חלק במגרש** = שטח ÷ 167 × השבר שבטבלה למגרש.
- **יח״ד** = חלק במגרש × מספר יחידות הדיור במגרש.
- **שווי הזכויות** = חלק במגרש × שווי המגרש.
- **שווי במצב הנכנס** = שטח × שווי החלקה ÷ 21,258.
- **היטל השבחה משוער** = 50% × (שווי הזכויות − שווי במצב הנכנס).

**מסלולים** (`computeSimulationTracks`):
- היחידות מגיעות מהטבלה. בהגדרות המתקדמות אפשר לדרוס אותן במספר מ״ר קרקע ליח״ד.
- היטל ההשבחה מחושב לכל בעל זכויות:
  - בקומבינציה ובתמורות היזם משלם אותו;
  - בעלות+ הוא נוסף פעם אחת לעלות;
  - במזומן הוא מנוכה מהמחיר.
- מזומן, והחלק שנמכר ליזם בקומבינציה, מתומחרים **לפי מ״ר קרקע** (ברירת מחדל ₪6,900, השקול להנחה הקודמת של ₪760,000 ל-110 מ״ר). כך המחיר לא קופץ בגלל שינוי מספר היחידות בטבלה.

ברירות המחדל להנחות השוק נמצאות ב-`DEFAULT_CONFIG` בקובץ [`src/hooks/useSimulation.js`](src/hooks/useSimulation.js):

```javascript
{
  combinationPct: 35,
  sqmPerUnitOverride: null,   // ריק = לפי הטבלה
  costPerSqm: 11000,          // לפני מע״מ
  apartmentSizeSqm: 100,
  entrepreneurMarkup: 14.5,
  vatRate: 18,
  requiredEquityPct: 25,
  marketValueSqm: 25000,
  landValuePerSqm: 6900,
  entrepreneurProfitMargin: 18,
  bettermentLevyPct: 50,
  capitalGainsTax: 25,
  revenueSharePct: 45,
}
```

## הרצה

דורש Node.js 22 ומעלה.

```bash
npm install
npm run dev       # http://localhost:5173/
npm test          # vitest (כולל בדיקות פיננסיות ותכונות)
npm run typecheck # tsc
npm run lint
npm run build     # dist/
npm run test:e2e  # אחרי build: בדיקת פרטיות ודפדפן (Playwright)
```

לבדיקת נתיבי נכסים כמו ב-GitHub Pages:

```bash
VITE_BASE=/10027-33/ npm run build && npm run preview
```
